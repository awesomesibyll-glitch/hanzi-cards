              TAKE YOUR PRACTICE WITH YOU

              Install Hanzi Cards

              Windows

              In Microsoft Edge, open the … menu and choose More tools → Apps → Install this site as an app.

              iPhone

              In Safari, tap Share → Add to Home Screen. Keep Open as Web App enabled if shown, then tap Add.

              Ready for offline study

              Wait for “Ready offline” before disconnecting. Use GitHub Sync online to merge reviews and custom cards across devices. Safari and the Home Screen app may use separate storage.

              About the courses

              Chinese uses HSK 3.0 (2021). English uses community CEFR levels. English translations and levels were AI-generated and may contain errors. View vocabulary sources.

              Pronunciation

              Choose a voice and speed in Audio settings. Download the corresponding system voice for offline playback.

               STUDY ACROSS DEVICES

              GitHub Sync

              Merge your reviews and custom cards with an encrypted GitHub Gist. Sync online before switching devices.

              Create a GitHub token with Gists: Read and write under account permissions. Repository access is unnecessary.

              Choose a strong password of at least 12 characters. Use the same password on each device. The app keeps the token and password only while this window is open.

              On the first device, leave the ID blank to create it. On other devices, paste that ID and use a token from the same GitHub account.

               PRONUNCIATION

              Audio

              Human recordings are prepared for the current visible word and cached for offline replay. If a recording is unavailable, words and sentences use a matching voice on this device.

              For better Chinese speech, download an Enhanced/Premium Mandarin voice in iPhone Settings → Accessibility → speech/reading settings, then reopen this app. Only voices exposed by Safari can be selected.
              MAKE IT YOURS

              Study settings

              Card types · choose one or more

              Selected types alternate during study. Types with no eligible cards are skipped. For English, pinyin-only selection uses word dictation. Dictation hides the answer until you check it. Pinyin tones apply to Chinese. Reverse cards show the translation first and have a separate schedule. The new-word limit is shared across courses and directions. Reviews of previously studied cards always remain available.
