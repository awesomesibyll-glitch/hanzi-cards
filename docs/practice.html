Install Hanzi Cards

Windows

In Microsoft Edge, open the … menu and choose More tools → Apps → Install this site as an app.

iPhone

In Safari, tap Share → Add to Home Screen. Keep Open as Web App enabled if shown, then tap Add.

Ready for offline study

Wait for “Ready offline” before disconnecting. Use GitHub Sync online to merge reviews and custom cards across devices. Safari and the Home Screen app may use separate storage.

Pronunciation

Choose a voice and speed in Audio settings. Download the corresponding system voice for offline playback.

 STUDY ACROSS DEVICES

GitHub Sync

Merge your reviews and custom cards with an encrypted GitHub Gist. Sync online before switching devices.

Create a GitHub token with Gists: Read and write under account permissions. Repository access is unnecessary.

Choose a strong password of at least 12 characters. Use the same password on each device. The app keeps the token and password only while this window is open.

On the first device, leave the ID blank to create it. On other devices, paste that ID and use a token from the same GitHub account.
