# Third-party data

## Expanded web catalog

Chinese: Complete HSK Vocabulary v1.4 by Yanis Zafirópulos (Dr.Kameleon),
https://github.com/drkameleon/complete-hsk-vocabulary/tree/v1.4 . Repository
code/list organization is MIT (licenses/HSK-MIT.txt). Dictionary definitions
and Pinyin derive from CC-CEDICT by MDBG and contributors,
https://www.mdbg.net/chinese/dictionary?page=cc-cedict , CC BY-SA 4.0
(licenses/CC-BY-SA-4.0.txt). The converted Chinese records and adapted glosses
are redistributed under CC BY-SA 4.0, separately from the application source.
Changes: select HSK 3.0 (2021) new-1 through new-7 entries; use the first form,
retain up to four meanings, normalize fields and IDs, and add review metadata.
HSK 7 is displayed as the combined HSK 7–9 band. It is not a 2026 exam guarantee.

English–Russian: Vocab Bloom Hub English dataset v0.3.1,
Copyright (c) 2026 Aleksei Ryzhov / Vocab Bloom Hub,
https://huggingface.co/datasets/Fristail27/vocab-bloom-hub-en , CC BY 4.0.
See licenses/BLOOM-CC-BY-4.0.txt and licenses/BLOOM-NOTICE.txt.
Generated by language models and not human-verified: definitions, levels and
translations may contain errors. Records retain generated/generated_by_model.
Changes: select common non-obsolete English headwords with Russian translations,
deduplicate by headword, limit displayed translations and normalize the schema.
Selection/order uses factual frequency evidence from
https://github.com/first20hours/google-10000-english (Google/Norvig word counts).

English pronunciation recordings: Wiktionary/Wikimedia Commons contributors,
retrieved through https://dictionaryapi.dev/ . Each eligible clip is retained
unmodified, cached on the device, and displayed with a link to its Commons
source (author attribution) and its individual Creative Commons license.
Recordings are not bundled in the repository. Missing recordings use system TTS.

Expanded handwriting uses reference centerline guides for new characters and retains the original detailed outlines for the seven starter characters. Stroke direction and order checking use all original medians.

The expanded catalogs are shipped as segmented gzip JSON in web/data/ and docs/data/.
scripts/import-catalog.py documents the conversion inputs. Chinese stroke
graphics remain under their separate Arphic Public License, described below.

Original application source in this starter is provided under MIT (see LICENSE).
The six demonstration vocabulary entries were written for this project, and are not extracted from HelloChinese.

Character graphics and medians: Make Me a Hanzi by skishore, distributed through
chanind/hanzi-writer-data, derived from Arphic fonts. These data have a separate
Arphic Public License, not the application MIT license.

- https://github.com/skishore/makemeahanzi
- https://github.com/chanind/hanzi-writer-data
- https://raw.githubusercontent.com/chanind/hanzi-writer-data/master/ARPHICPL.TXT

The data preparation script copies license files from the installed dataset into
licenses/. Commit that directory when publishing generated assets. Preserve the
attribution and license for any additional imported vocabulary pack. HSK is a
classification label, not a claim of affiliation or certification.

Optional word audio is fetched for the current word. Mandarin recordings come
from Wikimedia Commons, including Lingua Libre contributions. Accent-labelled
English recordings are found via Free Dictionary API and direct Wikimedia
Commons lookup. The
app displays the source and Creative Commons license for the recording
being played. The downloaded audio files are unmodified.
